# ADR-0019: First-party Angular UI library and AG Grid wrapper
Status: Accepted (owner decision, 2026-11-08) — S1-09 implements the core set and S1-10 the rest (pending independent review); the UI foundation gate stays **closed** until the Frontend Architect, QA and Security Architect approve | Date: 2026-11-07, updated 2026-11-08 | Decision owners: Frontend Architect (cannot self-approve), independent frontend reviewer / Lead Solution Architect, Security Architect, QA lead (named approvers TBD)

Source: CLAUDE.md "P0 frontend component policy" and "Mandatory UI foundation first"; docs/frontend/COMPONENT_ARCHITECTURE.md, COMPONENT_INVENTORY.md, UI_FOUNDATION_FIRST.md; Blueprint v1.0 §3 ("Angular 20+; TypeScript; Tailwind CSS"), §5; Spec v3.2 "Screen and design standards" ("Azure portal layout with Clarity styling"). Decision log DL-017, DL-018, DL-033. Drafted by Claude Code (S1-01); decisions by the repository owner (sivanandanr), 2026-11-08.

## Context and requirements
All common controls built in-house; Kendo UI / PrimeNG reference only; AG Grid is the sole approved third-party grid, wrapped by the library. Feature screens are blocked until the foundation is approved by Frontend Architect, QA and Security Architect.

## Options considered
- **Layout A:** single app, library at `frontend/src/app/shared/ui/` behind an alias, deep imports blocked by lint only.
- **Layout B:** Angular CLI workspace with a library project and an app project.
- AG Grid Community (MIT) vs Enterprise (commercial).
- Angular CDK as infrastructure vs native `<dialog>`/Popover API only.

## Decision and rationale
Owner decisions (DL-017, 2026-11-08):
- **Layout B.** `frontend/` is an Angular CLI workspace:
  - `projects/iam-ui` — the library, package `@iam/ui`, primary entry `src/public-api.ts`;
  - `projects/iam-ui/grid` — secondary entry `@iam/ui/grid`, the only code that imports AG Grid (keeps AG Grid out of every bundle that shows no grid: first load 435 kB instead of 1.18 MB);
  - `projects/iam-portal` — the app; in S1-09 a component playground, not an IAM feature screen.
  The portal maps `@iam/ui` / `@iam/ui/grid` to the public API files only; ESLint refuses deep or relative imports into the library.
- **Angular 22.2** (newest stable, zoneless, Signals), **Node 24 LTS** (`frontend/.nvmrc`), TypeScript strict with strict templates; exact versions in `package.json` and `package-lock.json`.
- **AG Grid Community 36.3 (MIT).** No Enterprise features; no licence key.
- **Angular CDK 22.2 as infrastructure only:** overlay positioning (dropdown) and Dialog (focus trap, `aria-modal`, Escape, focus return). Every visible control is ours.
- **Tailwind 4.3** through PostCSS for page layout; its theme maps onto the design tokens. Library components use only the tokens.
- **Clarity is a visual reference only** — no `@clr/*` package and no copied CSS (ESLint refuses `@clr/*`).
- **Scope (DL-033):** core set in S1-09, the rest in S1-10 (below). Component names follow UI_FOUNDATION_FIRST (`iam-textbox`, `iam-dropdown`, …).

Implemented in S1-09:

| Area | Components / pieces |
|---|---|
| Tokens | `styles/tokens.css`: colour (light and dark, OS preference or `data-theme`), type, spacing, density, focus ring, layering, motion (off under reduced motion), breakpoints |
| Form plumbing | `iam-form-field` (label, required marker, hint, client and server errors), shared ControlValueAccessor base (Signals, NgControl binding, aria-invalid / aria-describedby / aria-required) |
| Controls | `button[iamButton]` (type="button" default; `loading` blocks clicks in the capture phase), `button[iamIconButton]` (required accessible name), `iam-textbox` (required maxLength, trim policy that never strips inner text or leading zeros), `iam-textarea` (counter, bounded growth), `iam-checkbox`, `iam-toggle` (role="switch"), `iam-radio-group` (fieldset, role="radiogroup"), `iam-dropdown` (WAI-ARIA select-only combobox; keyboard, type-ahead, optional search, debounced search capped at 100 characters, loading/error/empty states) |
| Overlays | `IamDialogService` + `iam-dialog`, `IamConfirmService` (alertdialog and Cancel-first focus for destructive actions; resolves true only on explicit confirm) |
| Feedback | `IamToastService` + `iam-toast-outlet` (polite for info/success, assertive for warning/error; max 5; errors stay until dismissed), `iam-validation-summary` (focusable alert; focus links only for safe ids), `readProblemDetails` (strict, bounded RFC 9457 reader) |
| Grid | `@iam/ui/grid` `iam-data-grid`: read-only, server-side paging and sorting; emits only allowlisted page sizes, sortable columns and in-range pages; the grid never reorders rows; plain-text cells (no renderer hook); CSP `styleNonce` from Angular `CSP_NONCE`; loading, error and empty states announced |

Implemented in S1-10 (revised after independent review, 2026-11-09):

| Area | Components / pieces |
|---|---|
| Dates | `date-only.ts`: ISO `yyyy-mm-dd` values only (no `Date` objects or time zones cross the API), leap years, month clamping, locale order and first day of week from `Intl`, strict typed-date parsing (4-digit year, real calendar dates). `iam-date-picker`: text entry plus a calendar dialog (APG date-picker grid: the selected day is the `aria-selected` gridcell; focus trapped, roving tabindex, arrows / Home / End / PageUp / PageDown / Shift+Page for years, navigation kept within years 1000–9999, Escape returns focus), `min` / `max` (validity re-checked when they change), readonly, validator errors (`iamDate`, `iamDateMin`, `iamDateMax`) that survive `setValidators` / `clearValidators`, Latin digits in every locale, bidi marks in typed separators ignored. `iam-date-range`: fieldset with two labelled pickers, required, `min` / `max` on both ends and end-before-start validation; a form reset or patch clears text that was not a date. Dates are formatted with Angular `LOCALE_ID` (en-US until a locale decision is made, DL-039) |
| Search | `iam-autocomplete`: WAI-ARIA editable combobox over a caller-supplied `search(query, AbortSignal)`; at least 2 characters whatever `minChars` says, empty text or a lone `*` never searches (DL-027), 250 ms debounce (bounded 0–2000 ms), query capped at 100 characters, at most 50 results shown with "refine your search" when the server says there are more; superseded requests aborted and late replies ignored; idle / too short / loading / results / error states in a live region; results are cleared as soon as the text changes and nothing is highlighted until the user moves to an option, so Enter never picks a result the user did not choose; no empty listbox; labels cleaned of control and bidi characters; editing the text clears the value, leaving restores the label; a form-written value shows `selectedOption.label` only when the option's value matches |
| Overlays | `[iamTooltip]`: supplementary text only (never the only label), on native buttons and links only, on hover after 300 ms and immediately on focus, hoverable, stays while its host has focus, Escape dismisses, `aria-describedby` added and removed, plain text capped at 200 characters |
| Grid | Filter bar (`filters` input: text and option filters, built from the shared textbox and dropdown); the query carries only allowlisted fields, text trimmed and capped (default 100), option values checked against the offered list, always from page 1; `filters` is left out when empty; the form is rebuilt only when the set of filter fields changes, and text typed but not applied survives paging and sorting. Export button (`exportAction(query, signal)`): the caller's endpoint gets an `IamGridExportQuery` (sort and filters, no paging; a sort on a non-sortable column is dropped), aborted if the grid is destroyed; the server authorizes, caps rows, audits and builds the file; the browser only downloads it, re-typed as `text/csv`, under a sanitised name, revoking the object URL after 1 s. Tab enters and leaves the read-only grid once (arrow keys move between cells). `neutralizeCsvCell` / `toCsvField` / `toCsvRow` document the formula-injection rule the server must apply |
| S1-09 follow-ups | `headingLevel` (2/3/4) on dialog, validation summary and grid; one source of disabled state (the form when bound, the `disabled` input otherwise); checkbox shows its own and server errors outside a form field; radio/checkbox/range errors never stale (computeds read the control revision); dropdown `clearable`; toasts pause while hovered or focused and resume with the time left (WCAG 2.2.1); raw `<input>` / `<select>` / `<textarea>` and plain `<button>` refused in portal templates (the theme selector now uses `iam-dropdown`); overlays removed after every test |

## Security and privacy impact
- **Dependency allowlist (complete control):** `scripts/check-dependencies.mjs` fails CI if `package.json` gains any package not approved in DL-018, or any version range; `.npmrc` sets `ignore-scripts=true` and `save-exact=true` for local installs too.
- **ESLint gates (guard rail, not a complete control):** HTML sinks (`[innerHTML]`/`[outerHTML]`/`[srcdoc]` in any case and `bind-`/`attr.` form, host bindings and `@HostBinding`, `innerHTML`/`outerHTML`/`srcdoc` by name or bracket access, `Renderer2.setProperty`/`setAttribute` with HTML or `on*` names, `insertAdjacentHTML`, `DOMParser.parseFromString`, `createContextualFragment`, any `.write()`), code execution (`eval` incl. `window.eval`, `Function` with or without `new`, string `setTimeout`/`setInterval`, `require`, non-literal or package `import()`), `bypassSecurityTrust*` (incl. bracket access), browser storage (`localStorage`, `sessionStorage`, `indexedDB`, `caches`, `document.cookie`, also through `window`/`globalThis`/`self`), other UI libraries, AG Grid outside `@iam/ui/grid`, Angular CDK in feature code, and deep or relative imports into the library. `scripts/lint-selftest.mjs` proves each gate fires: 60 checks (S1-10 adds the raw-control rule), including the bypass shapes found in review. Static rules can still be evaded by indirection (aliasing a method, computed names); code review remains part of the control.
- Everything user- or server-supplied renders as text; tests feed an HTML/script payload through labels, errors, options, dialogs, toasts, summaries and grid cells.
- The dropdown's selected label and the grid's sort/page values are presentation only; the API must validate and authorize again (BACKEND_INPUT_VALIDATION).
- No tokens or personal data in browser storage; the theme choice is held in memory.
- npm install scripts are not needed: CI installs with `npm ci --ignore-scripts`.
- **CSP (S1-10):** `index.html` carries `<iam-root ngCspNonce="IAM_CSP_NONCE">`; the host must replace the placeholder with a fresh random nonce on every response and send the matching header. The Angular build also stamps the placeholder on its `<script>` and stylesheet tags, so one substitution covers all. Angular component styles and AG Grid's theme (`styleNonce` from `CSP_NONCE`) use it. The browser tests run the production build under `default-src 'none'; script-src 'self' 'nonce-…'; style-src 'self' 'nonce-…'; img-src 'self' data:; font-src 'self'; connect-src 'self'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'; object-src 'none'; require-trusted-types-for 'script'; trusted-types angular angular#bundler` (`scripts/serve-e2e.mjs`), with no `unsafe-inline` or `unsafe-eval`, and fail on any violation. **The hosting BFF must implement the same substitution and policy** (BFF hosting story); served without substitution the nonce is the public placeholder and the policy gives no protection. Critical-CSS inlining stays off so no inline `onload` handler is emitted.
- **Exports:** the browser never builds an export from the rows it holds. The export endpoint must authorize the caller for the data and for exporting it, re-validate the filters and sort against its own allowlist, cap the rows, write an audit record, neutralize formula cells (a cell starting with tab, carriage return or line feed, or with `=` `+` `-` `@` or their full-width forms `＝` `＋` `－` `＠` after any leading spaces → leading `'`) and quote per RFC 4180. The download name is reduced to `[A-Za-z0-9._-]`, at most 100 characters, ending in `.csv`, never a Windows device name. Export failures show a generic message, never the server's.
- **Autocomplete:** the client bound (2–100 characters, 50 results, debounce, abort) limits load and disclosure but is not a control; the search API enforces authorization scope, query length, result caps and rate limits, and treats the text as literal (LIKE wildcards `%` `_` and `*` escaped, a minimum of non-wildcard characters enforced on the server, on both SQL Server and PostgreSQL).
- **Nonce placeholder:** the build ships `nonce="IAM_CSP_NONCE"` on its script and stylesheet tags. A host that serves it unsubstituted — or a policy written as `'nonce-IAM_CSP_NONCE'` to make it work — turns any HTML injection into script execution. The hosting BFF must substitute a fresh nonce per response and refuse to serve a page where the placeholder survives (R-030).
- **Test reports:** Playwright traces keep DOM snapshots, network bodies and cookies. Data is synthetic today; before any e2e test signs in or uses real-looking identities, traces must be turned off or redacted in CI (R-030).
- Server messages and toasts are cleaned to single-line plain text (control characters replaced; bidi overrides and zero-width characters removed; cut without splitting surrogate pairs); the ProblemDetails field map has no prototype.

## Independent review (2026-11-08)
Frontend-architecture and security reviews (AI agents, advisory; human approval still required) found, and S1-09 fixed: lint bypasses (above); the validation summary never actually hid (`:host` display overrode `hidden`; it now renders no content at all when there is nothing to report); focus calls ran before content rendered under zoneless change detection (searchable dropdown unreachable by keyboard; summary focus) — now `afterNextRender`; every dropdown trigger looked disabled (`:read-only` matched the `div`); the active option did not scroll into view; grid right-alignment and the column-state API were silent no-ops without their AG Grid modules (now registered, with AG Grid's validation module in development and tests, and tests fail on AG Grid console warnings); the page-size selector showed the wrong size; out-of-range pages gave nonsense ranges; sorting was possible while loading; the stale grid API was kept; control ids could not be set (now `controlId`, validated); `required` was declared separately from the validator (now derived from it unless overridden); the form-control subscription did not follow a swapped control; the checkbox dropped field error ids when it had a hint; dropdown closing did not mark the field touched, Tab from the search box left focus in the overlay, a pending search was not cancelled, and a value missing from the options showed the placeholder; confirmations lacked `aria-describedby`; dialogs focused the close button first and had no `disableClose`; the backdrop style lived in the app; error toasts could be pushed out by the cap; the playground showed raw API field names.

Deferred from S1-09 to S1-10 (done in S1-10 except SSR-safe ids, still open): heading-level inputs (dialog, summary and grid use `h2`), a single source for disabled state (the `disabled` input beside the form's disabled state), checkbox errors outside a form field, toast pause on hover/focus (WCAG 2.2.1), dropdown clear action, raw-control lint for feature templates, Playwright real-browser keyboard, focus-trap and visual tests, forced-colors mode, SSR-safe ids, and test isolation (a failing overlay test can leave an overlay that makes later tests in the same run fail).

- Portal: 4 tests (shell, theme without browser storage, client and ProblemDetails errors mapped to the form's labels and linked to fields).
- Dependency allowlist; ESLint gates + 51-check self-test; Prettier; production build with size budgets; `npm audit --omit=dev --audit-level=moderate` (runtime) and `npm audit --audit-level=high` (all; the 14 moderate dev-tooling findings are one minimatch advisory, R-028).
- Mutation checks: undoing review fixes each fails its tests — summary rendered without problems (1), search focus back to a microtask (1), AG Grid cell-style module unregistered (6, through the AG Grid warning check), page-size selection removed (1), close no longer marking touched (the 2 touched tests, plus 6 unrelated tests through a leaked overlay — see below). A CSS-only check of the hidden summary was first found not to detect the bug in jsdom and was replaced.
- CI: `frontend` job in `.github/workflows/pr.yml`. Results recorded in the S1-09 completion report.

S1-10 independent review (2026-11-09; frontend-architecture and security reviews by AI agents, advisory; human approval still required). Fixed, each with a regression test: date range ignored `min`/`max`; a control's own validator was lost when feature code called `setValidators`; `aria-selected` sat on a button (and no axe run had an overlay open); picker validity did not follow `min`/`max` changes; a range reset left unparsable text; Enter could commit a result from an older query, and pressed Enter picked the first result unasked; `minChars` could be set below 2 (empty search); a label could show beside a different value; labels were not cleaned of bidi characters; the CSV rule missed a leading line feed, leading spaces and full-width triggers; the export request carried paging, could start a download after the grid was destroyed, trusted the server's content type and revoked the URL at once; the grid filter form was rebuilt for a new array and lost unapplied text on paging; toast pause shared one flag for hover and focus and dropped focus on dismiss; the tooltip hid on mouse-leave while focused and could describe a custom element instead of its input; dates could be shown in digits the control could not read back; the calendar could page below year 1000; `revalidate` emitted a second `valueChanges`; the raw-control lint rule was case-sensitive; the CSP test checked part of the policy and never proved enforcement; the CSV browser test did not contain a formula cell; the focus-indicator test accepted any box-shadow and ignored focus lost to `<body>`; no daylight-saving time zone was tested. Found by the stricter browser checks: the grid page-size selector had no focus indicator, and Tab stopped on every grid cell.
